# Privacy Policy

## English

GD-Peeker does not collect personal information, file metadata, or file contents.

GD-Peeker does not transmit file contents to any server operated by the developer or by a third party. Files are fetched from Google Drive using the browser session that is already signed in, and the contents are rendered locally in Chrome.

GD-Peeker does not sell, share, or disclose user data to third parties.

File contents are kept in memory only while the viewer tab is open. GD-Peeker stores settings locally in Chrome storage, such as renderer preferences, default encoding, and UI language. It does not store Drive file contents.

## 日本語

GD-Peeker は、個人情報、ファイルのメタデータ、ファイル本文を収集しません。

GD-Peeker は、ファイル本文を開発者または第三者のサーバに送信しません。ファイルは、すでにログインしているブラウザの Google Drive セッションを使って取得され、Chrome の中だけで描画されます。

GD-Peeker は、ユーザーデータを第三者に販売、共有、開示しません。

ファイル本文は viewer タブを開いている間だけメモリ上に保持されます。GD-Peeker は、描画設定、既定の文字コード、表示言語などの設定だけを Chrome storage にローカル保存します。Drive のファイル本文は保存しません。
